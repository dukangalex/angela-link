# AI 接入说明（中立版）

这份说明写给任何要接入 AngelaLink 的 AI / agent。把方括号里的三项换成
用户在 AngelaLink「连接」页生成的值，其余照此执行即可。

## 连接参数

- 入口地址：[https://你的隧道域名]（Tailscale Funnel 或 Cloudflare 隧道给出）
- 设备名称：[设备名]（多台电脑时用它区分，指令里点名设备）
- 专用令牌：[令牌]（只保存在你的凭据保管处，不写进代码、日志或对话明文）

所有请求带请求头：`Authorization: Bearer [令牌]`。
接口前缀：`/agent/v1`。

## 接口一览

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/roots` | GET | 列出已授权的根目录别名与权限 |
| `/list?root=<别名>&path=<相对路径>` | GET | 列目录 |
| `/read?root=<别名>&path=<相对路径>` | GET | 读文件 |
| `/write` | POST | 写文件（JSON：root、path、content） |
| `/mkdir` | POST | 建目录 |
| `/search` | POST | 按文件名搜索（JSON：query，可选 root） |
| `/exec` | POST | 提交命令（仅当用户在本机开启命令执行时可用） |
| `/exec/<job_id>?wait_ms=20000` | GET | 长轮询命令状态/审批结果 |
| `/exec/<job_id>/cancel` | POST | 取消命令 |

路径一律用相对授权根的相对路径；绝对路径、含 `..` 的路径会被拒绝。

## 命令执行的规矩（开启时）

- 命令在写受限沙箱里跑：只能写当次工作区子目录与隔离临时目录。
- 有些命令会触发用户电脑上的审批弹窗：用长轮询等结果，120 秒未获批准即视为拒绝，不要重试绕过。
- 标注为强制确认的操作（强推、递归删除、系统工具、混淆脚本等）每次都要等用户确认。
- 提交时在 reason 字段用一句话说明这条命令干什么，方便用户审批。

## 安全边界（接入方须知）

- 令牌只代表「这台电脑上、已授权范围内」的操作权，不做任何范围外的尝试。
- 凭证目录（.ssh/.aws/.gnupg 等）与本程序数据目录被服务端硬保护，请求会被拒——这是设计，不是故障。
- 用户随时可以暂停连接或轮换令牌；收到 401 先报告用户，不要猜测新令牌。
